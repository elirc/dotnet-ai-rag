# Answers: lexical mechanics

For queue, the title-plus-content document scores five, the tag-only document scores three and the content-only document scores one. With minimumScore three, the first two survive. Query repetition does not add points because query terms are distinct. Repetition within a field does not add points because that field's tokens form a set.

The tokenizer splits queue-depth into queue and depth, while HTTP500 becomes http500. The domain stop words can remove incident, investigate and service entirely. These are exact mechanics, not a semantic understanding of operational language. A useful synonym proposal needs an explicit expansion or normalization rule and an evaluation of false positives.

Threshold is applied before truncation, and the comparison includes equality. Nonpositive topK or minimumScore returns empty. The method does not fill unused slots with below-threshold documents. A correct boundary test should compare identifiers and scores so returning the wrong qualifying document cannot pass merely because the count matches.

The tie order is descending score, ordinal case-insensitive title, then document identifier. Stable sorting alone would preserve input order among otherwise equal keys and therefore would not provide input-order-independent results. Production tests should exercise actual Guid ordering rather than relying on a Python numeric fixture or a casual string sort.

An explanation card should call the number a heuristic score and show matched terms. If it displays field contributions, the result contract must supply or recompute those contributions faithfully. Normalizing a score for a progress bar does not turn it into a probability, a confidence estimate or proof that the runbook explains the incident.
