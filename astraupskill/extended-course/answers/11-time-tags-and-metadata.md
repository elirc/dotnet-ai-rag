# Review notes: time, tags and AI metadata

The current incident creation default of now minus fifteen minutes is not observed onset evidence. A richer contract should distinguish estimated onset, detection and record creation, including unknown values and corrections. Captured log time bounds reproduce the query definition but not necessarily the original population after late ingestion. Selected IDs or snapshots address that separate problem.

JoinTags and SplitTags assume commas are separators. A tag containing a comma cannot round-trip as one value unless validation rejects it or representation changes. Case-insensitive deduplication, display spelling and retrieval tokenization are different layers. Joined storage length includes separators, and relational length enforcement needs appropriate provider evidence.

Ticket mock triage derives summary and suggestions from parsed input/default values. It is not an independent model classification. Deterministic investigation explicitly reports modelUsed false and confidence null. Field names containing AI do not override those facts. A future model integration needs mode-specific provenance, validation and evaluation.

Zero model token cost does not mean zero local resource cost. Cost records should identify what is measured, estimated or not applicable. Current provider pricing is outside this local source exercise and should be verified when implementing real billing. A strong UI labels mock, deterministic and model-assisted modes accurately rather than blending them into one confidence display.
